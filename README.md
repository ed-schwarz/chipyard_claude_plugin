# rtl-sim-tools

A Claude Code plugin marketplace. It holds one plugin, [rtl-sim](plugins/rtl-sim/README.md): skills for building and running Chipyard Verilator simulators, reading FST waveforms, and diffing RTL commit logs against spike.

```
/plugin marketplace add ed-schwarz/chipyard_claude_plugin
/plugin install rtl-sim@rtl-sim-tools
```
